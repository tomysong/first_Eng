# AI초딩영어 v.1

초등학교 5학년 학습자를 위한 모바일 우선 영어 회화 학습 앱입니다.

## 바로 사용하기 (배포 주소)

**https://tomysong.github.io/first_Eng/**

### 아이폰/아이패드에 앱처럼 설치하기

1. Safari로 위 주소를 연다.
2. 하단 가운데 **공유 버튼**(네모에 위쪽 화살표)을 누른다.
3. **홈 화면에 추가**를 누른다.
4. 홈 화면에 생긴 AI초딩영어 아이콘으로 실행하면 주소창 없는 전체 화면 앱으로 동작한다.

한 번 설치하면 오프라인에서도 열리고(서비스워커 캐시), 학습 기록은 그 기기에 저장됩니다.
App Store 배포는 Apple 개발자 계정(연 $99)과 심사가 필요해서, 일반 배포는 이 PWA 방식이 정답입니다.

## 친구와 함께 쓰기 (로그인 불필요)

서버 없이 기록이 각 기기 안에 저장되는 구조라 **계정/로그인 없이** 여러 명이 쓸 수 있습니다.

- **각자 기기가 있는 경우**: 친구도 위 주소를 열어 홈 화면에 추가하면 끝. 기록은 자동으로 따로 저장됩니다.
- **한 기기를 같이 쓰는 경우**: 앱을 열면 넷플릭스처럼 **"누가 공부할까요?" 프로필 선택 화면**이 먼저 나옵니다. 기본 프로필은 `서율`이고 영어 자기소개 이름은 `Seo-Yul`입니다. `＋ 새 프로필`로 이름만 등록하면 기록(레벨, 진도, 연속, 복습 카드, 대화)이 완전히 분리됩니다. 본 화면 우상단의 프로필 버튼으로 언제든 다시 전환할 수 있습니다.
- **AI 대화 키**: 가정마다 Google AI Studio에서 무료 Gemini 키를 만들어 입력하거나, 키 없이 로컬 연습 모드로 사용해도 됩니다.

## 아이 화면과 보호자 화면 분리

아이에게는 **테스트 · 오늘(오늘 완료 버튼 포함) · AI대화** 세 탭만 보입니다.
`🔒 보호자` 탭은 **보호자가 직접 만든 4자리 비밀번호**로 잠겨 있습니다(첫 사용 시 설정, 이 기기에만 해시로 저장).
열리면 그때만 **v1계획 · 1년맵 · 자료** 탭과 **AI API 키 설정**, **전체 프로필 학습 현황**(레벨·진도·연속·복습할 표현 수)이 나타납니다.

- 5번 틀리면 60초 동안 입력이 잠깁니다.
- 비밀번호를 잊으면 "비밀번호를 잊었어요"에서 두 자리 곱셈 확인 후 새로 만들 수 있습니다.
- "아이 화면으로" 버튼을 누르면 다시 잠기고, 앱을 껐다 켜도 잠긴 상태로 시작합니다.

기기 간 동기화(아이폰↔아이패드)가 필요해지면 그때 서버(Convex) + 진짜 로그인을 도입합니다.

## 로컬 실행

`index.html`을 브라우저로 열면 바로 동작합니다.

## 코드 구조

- `app.js`: 화면 렌더링, 이벤트 바인딩, AI 호출, 음성/녹음 기능 조립
- `modules/data.js`: 레벨, 테스트 문항, 커리큘럼, 대화문, 캐릭터, 1년 로드맵 데이터
- `modules/profiles.js`: 로그인 없는 프로필 분리와 프로필별 저장소 키 관리
- `modules/progress.js`: 날짜 스탬프와 혼합 진행 방식 자동 전환
- `modules/dom.js`: DOM 선택 헬퍼
- `sw.js`: PWA 오프라인 캐시와 최신 파일 우선 로딩

## AI 대화 연결

앱의 `AI대화` 탭에서 제공자를 선택하고 API 키를 입력한 뒤 `설정 저장`을 누릅니다.

- Gemini: Google AI Studio에서 Gemini API 키를 만든 뒤 입력합니다.
- OpenAI: OpenAI Platform에서 API 키를 만든 뒤 입력합니다. ChatGPT 무료/Plus 계정과 API 사용량은 별도입니다.
- 로컬 연습: API 키 없이 기본 회화 피드백만 사용합니다.

현재 버전은 개인 기기 테스트용이라 API 키를 브라우저 `localStorage`에 저장합니다. 공개 배포용으로 만들 때는 API 키를 프론트엔드에 두지 말고 서버 프록시에서 보호해야 합니다.
