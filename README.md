# AI초딩영어 v.1

초등학교 5학년 학습자를 위한 모바일 우선 영어 회화 학습 앱입니다.

## 실행

`index.html`을 브라우저로 열면 바로 동작합니다. 아이폰에서는 Safari로 열고 공유 버튼에서 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 포함 기능

- 10문항 사전 테스트
- Starter, A1, A1+ 레벨 판정
- v1 28일 회화 커리큘럼
- 28일 완료 후 복습 및 v2 업데이트 요청
- 최대 1년치 압축 로드맵
- 오늘의 회화 듣기와 한 문장 반복 듣기
- 브라우저 내장 음성 합성 기반 영어 발음 (미국 여성 음성 자동 추천 + 직접 선택 가능)
- 지원 브라우저에서 마이크 말하기 인식
- Gemini API 또는 OpenAI API 키를 이용한 AI 영어 대화
- AI 대화 친구 캐릭터 3종 (Sunny 토끼, Max 로봇, Coco 고양이) — 캐릭터별 말투와 목소리
- 내 목소리 녹음 후 원어민 발음과 비교 듣기
- 말하기 채점 단어별 시각화 (맞춘 단어 초록, 놓친 단어 회색)
- Day 7/14/21/28 복습 보스 미션 — 그 주 문장 3개를 말하기로 통과 👑
- 약한 표현 자동 수집 — 잘 못 말한 문장이 표현 카드에 🔁 복습 카드로 등장
- streak에 따라 자라는 홈 캐릭터 (7일 모자, 14일 안경, 28일 왕관)
- API 키가 없을 때 동작하는 로컬 회화 코치
- 학습일과 연속 완료 기록 저장 (하루 1회, 날짜 기반 연속 계산)
- PWA 지원: 홈 화면 아이콘, 오프라인 동작(서비스워커)

## AI 대화 연결

앱의 `AI대화` 탭에서 제공자를 선택하고 API 키를 입력한 뒤 `설정 저장`을 누릅니다.

- Gemini: Google AI Studio에서 Gemini API 키를 만든 뒤 입력합니다.
- OpenAI: OpenAI Platform에서 API 키를 만든 뒤 입력합니다. ChatGPT 무료/Plus 계정과 API 사용량은 별도입니다.
- 로컬 연습: API 키 없이 기본 회화 피드백만 사용합니다.

현재 버전은 개인 기기 테스트용이라 API 키를 브라우저 `localStorage`에 저장합니다. 공개 배포용으로 만들 때는 API 키를 프론트엔드에 두지 말고 서버 프록시에서 보호해야 합니다.

## 버전 운영

v1은 28일 완결판입니다. Day 28을 완료하면 앱은 `v1 완료` 상태로 전환되고, v1 복습 후 `v2 업데이트 요청`을 저장합니다.

나머지 1년치 흐름과 서버 저장 설계는 `VERSION_ROADMAP.md`에 정리되어 있습니다.
